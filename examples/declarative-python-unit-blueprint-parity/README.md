# Generated Unit blueprint parity reference

This reference is the first Phase F production-shaped reconstruction gate.

It deliberately does **not** generate or replace the production Transfer Vth plugin. Instead it proves that a Python/declarative plugin can express the same generic public Unit vocabulary required by the accepted Vth blueprint:

- Page / PageHeader / Workspace;
- titleless data-control PRIME;
- `fill-rows` PRIMARY composition;
- Metric units in the canonical metric-grid recipe;
- ScientificPlot in a fill-capable detached Panel;
- canonical resizable SplitPane with `reflowBelow`;
- Unit Table in the second split region;
- one lowered JavaScript Task projecting Plot + Table + Metrics.

The generator has no `transfer-vth-lab` branch and copies no production private CSS, DOM hooks, task runtime or domain store. The production native blueprint is used only by the release gate as independent reconstruction evidence.

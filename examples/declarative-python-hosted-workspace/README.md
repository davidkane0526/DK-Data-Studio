# Generated hosted workspace reference

This Phase F reference generates two ordinary Plugin API 1.19 packages from the same Unit-first composition:

- a TOP workbench with `workspace.role: top` and a dedicated reusable project window;
- a Tool Workspace using the same public lifecycle but `pluginType: tool`.

The generator owns no host implementation. It emits the existing Activity + Page + TopWorkspace registrations and the existing manifest workspace/window contracts. Scientific renderer dependencies are derived from generated plot content. Parameter PRIME projection remains the canonical Unit data-control contract.

No private CSS, dedicated-window fork, Presenter branch, specialized Unit or alternate runtime is generated.

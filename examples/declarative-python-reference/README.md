# Declarative Python reference

Run:

    python build_plugin.py

The generated folder is an ordinary DK Data Studio Plugin API 1.19 workbench. The authoring source is Python; UI composition is emitted through the existing Unit Templates only.

This reference deliberately exercises a page header action, a titleless parameter PRIME with a two-column form recipe, a Note Unit, and a ScientificPlot Unit. It contains no plugin stylesheet and does not modify Core, Presenter, or Unit Templates.

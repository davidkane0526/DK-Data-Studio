# Pulse Unit-only Shadow Reconstruction

Parallel SDK evidence for `builtin.pulse-analysis`. It does not replace or modify the production plugin. All visual composition is made through `ctx.ui.unitTemplates`; no plugin CSS is shipped.

This second real migration specifically validates nested ownership: the raw diagnostic PlotView delegates movement to its enclosing `scientific-secondary` PRIME, while result PlotViews retain their own position/export owner. It also validates responsive SplitPane reflow through the public Unit contract.

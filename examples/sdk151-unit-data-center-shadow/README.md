# Data Center Unit-only Shadow Reconstruction

Parallel SDK evidence for `builtin.data-center`. It does not replace or modify the production plugin. All visual composition is made through `ctx.ui.unitTemplates`; no plugin CSS is shipped.

This fourth real migration validates the non-scientific-first side of the same 41-Unit contract: data-primary browsing, bounded table preview, formula/workflow/provenance tools, dialog/menu semantics, and a `plotView:prime-contained` chart preview whose enclosing scientific-secondary PRIME is the only position owner.

The migration also validates the generic interactive Chip contract used by formula-reference tokens: the semantic token remains a canonical Chip while Core supplies native-button interaction semantics.

## Live side-by-side stage

As of v3.71.28 this shadow remains historical side-by-side evidence for the production cutover. Through the dependency-gated `builtin.data-center/live` domain service it consumes the same production Artifact/Selection/Formula/Workflow/Provenance state and invokes the same production actions. The production Data Center presentation is now Unit-owned as well, so `productionReplaced` is true; the shadow is retained only to prove the pre-cutover round-trip and presentation parity baseline.

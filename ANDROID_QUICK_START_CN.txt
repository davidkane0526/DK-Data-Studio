Graphene Resonance Studio 3.16.0-plugin.1 - Android 快速安装测试
================================================================

本文件对应 Git 分支：plugin
不要在 main(v3.14 baseline) 上执行这些 Android 开发步骤。

一、Windows 电脑先准备
----------------------
1. Node.js 22.13 或更高兼容版本
2. JDK 17
3. Android Studio
4. Android Studio -> SDK Manager -> Android 16 / API 36
5. 设置 ANDROID_HOME，通常为：
   %LOCALAPPDATA%\Android\Sdk
6. 将：
   %ANDROID_HOME%\platform-tools
   加入 PATH

可先双击：
CHECK_ANDROID_ENV.cmd

二、直接生成可安装 APK
----------------------
双击：
BUILD_ANDROID_DEBUG.cmd

第一次会下载 React Native / Expo 依赖，因此需要联网并等待较长时间。

成功后 APK 位于：
mobile-dist\Graphene-Resonance-Studio-debug.apk

三、安装到手机
--------------
手机打开：开发者选项 -> USB 调试
USB 连接电脑并允许调试授权。

然后双击：
INSTALL_ANDROID_APK.cmd

也可以命令行：
adb install -r mobile-dist\Graphene-Resonance-Studio-debug.apk

四、直接编译 + 安装 + 启动
--------------------------
如果手机已连接，或 Android 模拟器已启动，可以直接双击：
RUN_ANDROID_DEVICE.cmd

五、Android 版结构
-----------------
React Native / Expo 原生壳
 -> Android WebView 离线加载完整软件
 -> plugin 架构
 -> 与桌面端相同的 src/science 科学计算引擎

Android 版不需要连接桌面软件才能分析数据。
文件选择通过 Android 系统 DocumentPicker；CSV/JSON/SVG/PNG 通过 Android 分享/保存面板导出。

详细说明：
mobile\README_ANDROID_CN.md

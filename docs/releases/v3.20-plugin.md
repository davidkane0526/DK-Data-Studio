# v3.20.0-plugin.2

- Unified the desktop header into one adaptive command row.
- Kept Activity and plugin command overflow priority-aware instead of wrapping into a second row.
- Normalized ordinary UI typography/control density with semantic CSS tokens.
- Consolidated all Windows CMD workflows behind `GRS.cmd` and `GRS_GUI.cmd`.
- Added a WinForms developer/build GUI backed by a single PowerShell action runner.
- Moved LAN update service to `services/update-server/`.
- Moved updater default config to `config/`.
- Moved operational guides/release snapshots under `docs/`.
- Added project-structure, development, toolbox and next-session handoff documentation.

## v3.20.0-plugin.2 Windows toolbox repair

- Fixed the PowerShell `$Args` collision that dropped command arguments such as `install`, `start`, and `run check`.
- Rebuilt `GRS_GUI.cmd` / `grs-gui.ps1` around a responsive FlowLayoutPanel card layout instead of fixed `(X,Y)` coordinates.
- Added dependency repair and environment diagnostics actions.
- Added regression checks that prevent reintroducing the argument-forwarding and WinForms constructor bugs.

GRS Android 最简步骤
====================

推荐方式：双击 GRS_GUI.cmd -> “Android”。

1. 检查环境：
   GRS.cmd android-check
2. 构建 APK（release）：
   GRS.cmd android-build
3. 安装已有 APK：
   GRS.cmd android-install
4. 连接设备直接运行：
   GRS.cmd android-run

APK 输出：
mobile-dist\Graphene-Resonance-Studio.apk

release 签名目录（首次构建自动生成，后续复用）：
%LOCALAPPDATA%\GrapheneResonanceStudio\android-signing
建议备份该目录，以便未来 APK 可覆盖安装。
若手机上仍有旧签名版本，首次切换需先卸载旧版后再安装。

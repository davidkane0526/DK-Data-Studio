DK Data Studio / PyDroid 共用工具链（Windows）
=============================================

推荐统一根目录：
  DK_TOOL_ROOT=D:\Code
  DK_CACHE_ROOT=D:\Code\BuildCache

当前两套构建脚本都会优先复用这两个用户环境变量。
如果未设置，而机器上存在 D:\Code\NodeJs\node.exe，也会自动把 D:\Code 识别为共享工具根目录。

建议一次安装、长期复用的工具：
1. Git
2. Node.js（当前 PyDroid 构建脚本默认 24.19.0；现有 D:\Code\NodeJs 可直接复用）
3. Corepack / pnpm（PyDroid 使用；DKDS 仍可使用 npm）
4. JDK 21（Temurin 或 Microsoft OpenJDK；包含 java/keytool）
5. Android SDK：platform-tools、cmdline-tools、platforms;android-36、build-tools;36.0.0
6. Python 3.12.x（PyDroid Android/桌面运行时需要；DKDS 本身不需要）

不建议全局安装：
- Electron：版本由各项目 package.json 锁定；只共享 BuildCache\electron 下载缓存。
- electron-builder：版本由项目决定；只共享 BuildCache\electron-builder 缓存。
- Gradle：使用各项目 Gradle Wrapper；只共享 BuildCache\gradle。
- npm/pnpm 项目依赖：仍由各项目声明；下载内容通过公共 cache/store 复用。

推荐目录结构：
D:\Code\
  NodeJs\
  Java\
    temurin-21\current\     （或 jdk-21\）
  Python\
    3.12\
  Android\Sdk\              （可选；已有 %LOCALAPPDATA%\Android\Sdk 也会复用）
  BuildCache\
    npm\
    pnpm-store\
    electron\
    electron-builder\
    gradle\
    downloads\

检查 DKDS：
  DKDS.cmd toolchain
  DKDS.cmd doctor
  DKDS.cmd android-check

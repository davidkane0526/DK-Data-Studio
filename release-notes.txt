Graphene Resonance Studio 3.17.0-plugin.1
Branch: plugin

- Added a core Plugin Manager page accessible from the top toolbar.
- Plugin Manager shows plugin name, ID, version, API version, capabilities, runtime contributions and activation status.
- Added search and status filters for all / enabled / disabled / error plugins.
- Plugins can be enabled, disabled, retried and reloaded without restarting the whole application.
- Plugin enable preferences persist locally under grs.plugin.preferences.v1 and are independent of project files.
- Disabling/reloading a plugin captures its current project state before runtime cleanup.
- Re-enabling a plugin restores its namespaced state for the current project.
- Project serialization now preserves data for disabled or temporarily unavailable plugins instead of deleting their namespace.
- Failed partial plugin activation is rolled back cleanly, avoiding leaked commands/registry/UI contributions before Retry.
- Added Restore Defaults and Copy Diagnostics actions.
- Plugin Manager UI includes compact/touch layouts for browser and React Native Android builds.
- Android shell version advanced to 0.3.0 / versionCode 3 so plugin-manager builds can update earlier test APKs.

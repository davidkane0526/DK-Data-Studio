# Workspace Safeguards

Built-in infrastructure plugin for shell layout and import integrity.

- lets the secondary workspace area consume all genuinely free top-bar width before using “更多工作区”;
- keeps the import file action row reachable while large file lists scroll independently;
- preserves peak results for unchanged datasets during incremental import, while new/replaced datasets may be auto-detected;
- warns and asks for confirmation when pending imports have duplicate names or match an existing source file.

This plugin does not own scientific algorithms. It protects previously established analysis state from unrelated imports.

# Aurora Pop 2.2

Aurora Pop is a bundled Theme Contract 3.9 profile. It owns appearance tokens only; Core owns Component Identity, Material Role, rendering, layout and scientific color precedence.

Version 2.2 keeps Aurora token-only and restores the intended high-contrast interaction states: in light mode, canonical primary/secondary/active/selected actions and active/selected tabs use filled violet/cyan surfaces with white labels. Core remains the sole renderer; the theme only supplies appearance tokens. Dedicated TOP windows consume the same profile through the shared Core Theme bootstrap.
